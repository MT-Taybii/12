# JavaScript Name Greeting App 👋

A simple and interactive JavaScript project that asks users to enter their name, displays a personalized welcome message, and demonstrates how to use the `indexOf()` method to find a character in a string.

## ✨ Features

- **User Input:** Prompts users to enter their name.
- **Personalized Greeting:** Displays a welcome message using the entered name.
- **Character Search:** Uses JavaScript's `indexOf()` method to find the position of the letter `"y"` in the name.
- **DOM Manipulation:** Updates webpage content dynamically using `textContent`.
- **Input Validation:** Displays an alert if the user doesn't enter a name.
- **Console Output:** Logs the character's index to the browser console.

## 🛠️ Technologies Used

- HTML5
- JavaScript

## 🚀 How It Works

1. The application asks the user to enter their name using `prompt()`.
2. If a name is entered, an alert displays a personalized greeting.
3. The webpage updates the element with the ID `welcome` to show the user's name.
4. The `indexOf("y")` method finds the position of the first occurrence of the letter `"y"` in the entered name.
5. The result is displayed in the browser console and on the webpage.
6. If no name is entered, an alert asks the user to refresh the page and try again.

## 💻 Example

**Input:**
```text
Tayyab
```

**Output:**
```text
Hello, Tayyab! Welcome to our website.
Welcome, Tayyab!
Welcome, 2
```

The index of `"y"` is `2` because JavaScript string indexing starts at `0`.

- Displaying output with `console.log()` and `textContent`.
